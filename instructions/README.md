# Template Instructions Only

This folder contains template instruction files that are copied into other repositories during setup.

These files are not the active AI assets for this repository.

## Important

- Do not treat files in this folder as runtime instructions for agents.
- The active instruction assets used by agents in this repository are under `.github/instructions/`.
- Other tools may also use copied assets from `.github/` (for example `.claude/` if configured in a target repo).

## Maintainer note

Use these files as source templates. Keep names and content in sync with install scripts and pack configs.
