# Engineering standards

Canonical, reusable standards for projects. These are **stack and tooling
policy**, not Spec Kit product governance.

| Source in this repo | Typical install path in a project |
|---|---|
| `TESTING_STANDARDS.md` | `docs/TESTING_STANDARDS.md` (or project-equivalent) |
| `TECH_STACK.md` | `docs/tech-stack.md` (or project-equivalent) |

Point agent context (`AGENTS.md`, Cursor rules) at these files. Do **not** copy
framework/library choices into `.specify/memory/constitution.md` — keep the
constitution for product principles and Domain Constraints.

See also: [`../specify/`](../specify/) for the standard Spec Kit constitution.
