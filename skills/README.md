# Template Skills Only

This folder contains template skill folders that are copied into other repositories during setup.

These files are not the active AI skills for this repository.

## Important

- Do not treat skills in this folder as runtime assets.
- The active skill assets used by agents in this repository are under `.github/skills/`.
- Other tools may also use copied assets from `.github/` (for example `.claude/` if configured in a target repo).

## Maintainer note

Use these folders as source templates. Keep names and content in sync with install scripts and pack configs.
