# Template Prompts Only

This folder contains template prompt files that are copied into other repositories during setup.

These files are not the active AI prompts for this repository.

## Important

- Do not execute prompts from this folder as if they are live assets.
- The active prompt assets used by agents in this repository are under `.github/prompts/`.
- Other tools may also use copied assets from `.github/` (for example `.claude/` if configured in a target repo).

## Maintainer note

Use these files as source templates. Keep names and content in sync with install scripts and pack configs.
