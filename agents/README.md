# Template Agents Only

This folder is reserved for template agent files that are copied into other repositories during setup.

Files here are not active AI agents for this repository.

## Important

- Do not treat this folder as a runtime agent location.
- The active agent assets used by agents in this repository are under `.github/agents/`.
- Other tools may also use copied assets from `.github/` (for example `.claude/` if configured in a target repo).

## Maintainer note

If template agents are added here, keep names and content in sync with install scripts and pack configs.
